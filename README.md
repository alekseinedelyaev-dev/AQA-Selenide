
# Домашнее задание «2.2. Selenide»

![Java CI with Gradle](https://github.com/alekseinedelyaev-dev/AQA-Selenide/actions/workflows/gradle.yml/badge.svg)

## Описание проекта

Автоматизированное тестирование формы заказа доставки банковской карты.

Проект выполнен в рамках обучения в Нетологии.

## Используемые технологии

- Java 17
- Gradle
- Selenide 6.19.1
- JUnit 5
- GitHub Actions

## Задача № 1. Заказ доставки карты

Автотест проверяет успешную отправку формы с корректными данными.

Проверяемые условия:

- Город является административным центром субъекта РФ.
- Дата встречи рассчитывается относительно текущей даты.
- Фамилия и имя вводятся на русском языке.
- Телефон соответствует требованиям формы.
- Установлено согласие на обработку персональных данных.
- После отправки появляется уведомление об успешном бронировании.
- Ожидание успешного уведомления ограничено 15 секундами.

## Запуск приложения

```bash
java -jar ./artifacts/app-card-delivery.jar
```

Приложение доступно по адресу http://localhost:9999.

## Запуск автотестов

Windows (PowerShell):

```powershell
.\gradlew.bat clean test "-Dselenide.headless=true"
```

Linux:

```bash
./gradlew clean test -Dselenide.headless=true
```

## GitHub Actions

Автотест запускается автоматически при отправке изменений в репозиторий.

Статус последней сборки отображается в бейдже в начале документа.
